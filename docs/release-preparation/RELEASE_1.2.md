U-AVF lets you run Ubuntu Desktop and experimental Windows 11 ARM64 on Android without root.

## What's new

- Windows 11 ARM64 installation directly from an ISO.
- Ubuntu GNOME with VirGL/H.264 and experimental Mavk graphics for GNOME and KDE Plasma.
- Completely redesigned UI with three themes.
- Interface available in six languages.
- New device diagnostics and compatibility testing system.
- Major code refactoring, bug fixes and build improvements.

For installation instructions, requirements and known issues, see the [README](https://github.com/dt0-imsyu/U-AVF/blob/main/README.md).
